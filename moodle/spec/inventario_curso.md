# Inventario y Especificación del Curso Moodle (1665 — Digitalización ASIR)

Este documento especifica la estructura ideal de secciones, tipos de recursos y actividades recomendadas para configurar o migrar el curso en la plataforma Moodle del centro, adaptándose a las 30 horas del módulo.
