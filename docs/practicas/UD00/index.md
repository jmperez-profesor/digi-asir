# Prácticas UD00: Configuración del Entorno Colaborativo y Git

## Práctica 0.1: Configuración Inicial del Entorno de Trabajo

### Objetivo
Preparar el entorno de trabajo local y remoto mediante Git, GitHub y Python para el desarrollo de las prácticas del módulo.

### Pasos a Realizar
1. **Configuración de identidad en Git**:
   ```bash
   git config --global user.name "Tu Nombre"
   git config --global user.email "tu.correo@centro.es"
   ```
2. **Creación y clonación del repositorio de prácticas**:
   - Clonar el repositorio asignado para el módulo.
3. **Verificación del entorno Python y dependencias**:
   - Comprobar la versión de Python instalada (`python3 --version`).
   - Crear y activar un entorno virtual (`python3 -m venv venv`).
   - Instalar dependencias base (`pip install -r requirements.txt`).

- ¿Por qué es una buena práctica utilizar entornos virtuales (`venv`) en la administración de sistemas Python?
