# Prácticas UD03: Automatización y Análisis de Logs con Python

## Práctica 3.1: Análisis Automatizado de Registros (Logs)

### Objetivo
Utilizar Python y bibliotecas de análisis de datos para procesar registros de acceso a un servidor web y detectar patrones sospechosos.

### Tareas a Realizar
1. Descargar o generar un fichero de log simulado (`access.log`).
2. Utilizar un cuaderno Jupyter (`analisis_logs.ipynb`) para:
   - Cargar y estructurar los datos del log utilizando `pandas`.
   - Generar gráficos de peticiones por dirección IP y código de estado HTTP (`matplotlib`).
   - Identificar posibles ataques de fuerza bruta o escaneos web.

### Enlaces y Recursos
- Consulta el [Cuaderno Jupyter Interactivo de Análisis de Logs](analisis_logs.ipynb).
