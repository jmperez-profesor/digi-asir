# Prácticas UD7: Memoria del Proyecto de Transformación Digital

## Actividad 7.1 — Memoria integradora (RA6, CE a–k)

**Objetivo**: redactar la memoria técnica del proyecto (8–12 páginas + anexos) para una empresa real o ficticia del entorno, siguiendo el método de [UD7](../../UD7/index.md).

**Entregables**:

1. Diagnóstico + DAFO (CE a, b, c).
2. Objetivos medibles priorizados (CE a, e).
3. Diseño técnico con diagrama de arquitectura (CE d, f, h, i).
4. Análisis de brechas de seguridad + plan de formación (CE g, k).
5. Roadmap con hitos, costes y riesgos (CE e, j, k).
6. Resumen ejecutivo de una página (CE j).

**Lista de verificación**: cada CE de la **a** a la **k** debe aparecer subrayado en la memoria. Los CE d, f, i, j se comparten con el proyecto intermodular: coordina el formato con tu equipo.
