# Prácticas UD7: Proyecto Integrador de Transformación Digital

## Actividad Práctica 7.1: Elaboración del Plan de Transformación Digital
- **Objetivo**: Diseñar la memoria técnica de transformación digital para una empresa real o simulada.
- **Tareas**: Confeccionar el lienzo de transformación digital, definir la integración de datos y documentar las brechas de seguridad y mitigación.
