# UD4 — Ejercicios de autoevaluación (RA4)

> Repaso de los CE RA4.a–f.

1. ¿En qué tipo de tareas rinde la IA en una empresa? Pon un ejemplo de sysadmin. (CE a)
??? success "Solución"
    Donde hay volumen y repetición: p. ej., filtrar 300 alertas semanales quedándose con las 5 anómalas.

2. Completa la cadena dato → … → rentabilidad. (CE b)
??? success "Solución"
    Dato → Big Data → análisis/IA → decisión (evitar paradas, fraudes, mal stock) → rentabilidad.

3. ¿Por qué se dice que la IA «no es neutral»? (CE c)
??? success "Solución"
    Aprende de datos que pueden contener sesgos y sus errores (alucinaciones) tienen consecuencias: hay que supervisar.

4. Nombra dos sectores con implantación fuerte de IA. (CE d)
??? success "Solución"
    Banca (fraude) y salud (imagen diagnóstica), entre otros (logística, industria, AIOps).

5. ¿Qué lenguaje asociarías a un pipeline de datos con ML y por qué Python? (CE e–f)
??? success "Solución"
    Python: ecosistema (pandas, scikit-learn) y legibilidad para scripts operativos del ASIR.
